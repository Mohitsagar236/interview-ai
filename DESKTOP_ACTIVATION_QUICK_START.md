# 🚀 Desktop App Activation - Quick Start Guide

## For Users: How to Activate Your Desktop App

### Step 1: Get Your Activation Code (Website)

1. Go to **https://interviewai.com** and log in to your account
2. Click on your **Profile** in the top right corner
3. Scroll down to the **"Desktop App Activation"** section
4. Your activation code will be displayed: `XXXX-XXXX-XXXX-XXXX`
5. Click the **"Copy Code"** button

### Step 2: Activate Desktop App

1. Download and open the **Interview AI Desktop App**
2. You'll see an activation window
3. **Paste your activation code** in the input field
4. Click **"Activate Desktop App"**
5. Done! ✅ Your app is now activated

### That's It!

Your desktop app is now connected to your account and your credits are automatically synced.

## 💡 Tips

### Need a New Code?
- Go to your Profile page
- Click **"Regenerate"** button
- Your old code will stop working
- Copy the new code and use it

### Switching Computers?
- Just enter the same activation code on your new computer
- Or generate a fresh code for extra security

### Forgot Your Code?
- No problem! Just log in to the website
- Go to Profile → Desktop Activation
- Your code is always there

### Security Tip
If you think someone else might have your code:
1. Go to Profile page
2. Click **"Deactivate"** to disable current code
3. Click **"Generate"** to get a new code

## 🎯 Common Questions

**Q: Do I need to log in on the desktop app?**
A: No! Just enter the activation code. No password needed.

**Q: Can I use the same code on multiple computers?**
A: Yes! Use the same code on all your devices, or generate separate codes for security.

**Q: What if my activation code doesn't work?**
A: Generate a new code from your profile page and try again.

**Q: How long does the code last?**
A: Your activation code works until you deactivate it or generate a new one.

**Q: Is my activation code secure?**
A: Yes! The code is unique to your account. If you suspect it's compromised, regenerate it immediately.
