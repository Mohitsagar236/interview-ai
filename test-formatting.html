Algorithm Analysis

The modular arithmetic approach ensures efficient calculation:

  1. Start with day d
  2. Subtract a days
  3. Add 7 to handle negative results
  4. Apply modulo 7: $(d - a + 7) \bmod 7$
def dayBefore(d: int, a: int) -> int:
    """
    Calculate the day of week a days before day d.
    
    Args:
        d: Day of week (0=Sunday, 6=Saturday)
        a: Number of days before
        
    Returns:
        Day of week a days before d
        
    Time Complexity: O(1)
    Space Complexity: O(1)
    """
    return (d - a + 7) % 7

The time complexity is $O(1)$ because we perform only constant-time arithmetic operations.
