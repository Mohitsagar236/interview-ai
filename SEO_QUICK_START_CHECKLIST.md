# SEO Quick Start Checklist for InterviewAI

## ⚡ IMMEDIATE ACTIONS (Do Right Now!)

### 1. Update Your Domain URL
**CRITICAL**: Replace `https://interviewai.app/` with your ACTUAL domain in:
- [ ] `public/index.html` (multiple locations in meta tags)
- [ ] `public/sitemap.xml` (all URL entries)
- [ ] `public/robots.txt` (sitemap URL)

### 2. Submit to Google (15 minutes)
- [ ] Go to https://search.google.com/search-console
- [ ] Add your website
- [ ] Verify ownership (HTML file upload or DNS verification)
- [ ] Submit sitemap: Settings → Sitemaps → Add `sitemap.xml`
- [ ] URL Inspection → Request Indexing for homepage

### 3. Submit to Bing (10 minutes)
- [ ] Go to https://www.bing.com/webmasters
- [ ] Import from Google Search Console (easiest method)
- [ ] Or manually add and verify
- [ ] Submit sitemap.xml

## ✅ SEO HEALTH CHECK (Monthly)

Run these checks monthly:

### Technical SEO
```
✓ Site loads in < 3 seconds
✓ Mobile-friendly (Google Mobile-Friendly Test)
✓ HTTPS enabled
✓ No broken links
✓ Sitemap is up to date
✓ No crawl errors in Search Console
✓ All images have alt text
✓ Meta descriptions on all pages
```

### Content SEO
```
✓ H1 tag on every page
✓ Proper heading hierarchy (H1 → H2 → H3)
✓ Keywords used naturally
✓ Internal linking between pages
✓ Fresh content published this month
✓ No duplicate content
```

### Off-Page SEO
```
✓ New backlinks acquired
✓ Social media active
✓ Brand mentions increasing
✓ Domain authority improving
✓ No toxic backlinks
```
