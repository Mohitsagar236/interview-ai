# Windows SmartScreen Bypass Guide

When you download and run Interview AI Assistant for the first time, Windows may show security warnings. **This is normal for all new applications** that aren't code-signed yet.

## How to Install (Step-by-Step)

### Step 1: Download Warning
When downloading, you might see:
- **"Interview-AI-Setup.exe - This file is not commonly downloaded"**

**Action**: Click **"Keep"** or **"Save anyway"**

### Step 2: SmartScreen Warning 
When you run the installer, Windows Defender SmartScreen will show:

**"Windows protected your PC"**
**"Microsoft Defender SmartScreen prevented an unrecognized app"**

### ✅ How to Bypass (Safe)

1. Click **"More info"** (blue link at the bottom)
2. Click **"Run anyway"** button that appears
3. The installer will start normally

## Why Does This Happen?

- **Code Signing Certificate**: Professional certificates cost $300-400/year
- **New Application**: Windows hasn't seen this app downloaded enough times yet
- **Open Source**: Our app is completely open-source and safe

## Is It Safe?

✅ **YES** - The app is:
- Open source (view all code on GitHub)
- Built with secure Electron framework
- No malware, spyware, or viruses
- Scanned by GitHub's security tools
