Quick Start Guide

Follow these four simple steps to get Interview AI up and running. For full details, see the Documentation.

1

Download & Install

Grab the installer from the Download section or use the web app. Run the installer and follow the prompts (Windows 10/11 supported).

2

First Run & Audio Setup

Open Interview AI and run audio setup: pick your microphone, run a recording test, and allow permissions when prompted.

3

Configure Interview

Create a new interview, choose a template, select language & analysis level, and connect integrations (ATS, calendar, or SSO).

4

Run & Review

Start the session — transcripts and AI insights appear in real time. Export or share reports after the interview.
